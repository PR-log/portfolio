## 구성

단일 HTML 파일입니다. 외부 의존성이 없고, 라이트/다크 테마와 반응형 레이아웃을 지원합니다.

```
├── index.html    사이트 전체
├── .nojekyll     GitHub Pages의 Jekyll 처리 비활성화
└── README.md
```

수정하려면 `index.html`을 편집하고 push하면 됩니다. 반영까지 보통 1분 이내 걸립니다.
